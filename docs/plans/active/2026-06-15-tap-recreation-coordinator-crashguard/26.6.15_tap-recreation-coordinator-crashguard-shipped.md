## Per-phase summary

Phase 1 shipped snapshot/restore foundations and the service-restart ordering hook. `SettingsManager`, `VolumeState`, and `AudioEngine` now snapshot routing, follows-default state, persisted selection, and in-memory selection; `AudioDeviceMonitor` exposes a pre-churn restart hook and HAL-free restart event emitter.

Phase 2 shipped the serialized recreation transaction and switch-task quiescence. Restart and permission recreation now go through one active transaction with coalesced reasons, pre-churn snapshot capture, cancellation/drain of in-flight switch work, suppression-bound restore/finalize, and guarded post-await switch commits.

Phase 3 shipped permission-driven tap construction. New taps use `muteOriginal: permissionConfirmed`, with a constructor-time test hook so XCTest observes the value before real CoreAudio activation.

Phase 4 shipped restart-close reconciliation. Finalization restores the transaction snapshot, then reconciles missing single-mode routes and multi-device selections against the current device list before suppression clears.

Phase 5 removed crash-time HAL cleanup. `CrashGuard.swift` was deleted, all install/track/untrack call sites were removed, normal aggregate-device teardown remains intact, and `OrphanedTapCleanup` now has injected dependencies for HAL-free tests.

Phase 6 aligned docs and the changelog with the shipped model: no crash signal handler, startup orphan cleanup retained, SIGTERM/SIGINT graceful shutdown retained, and H4/H5 moved to fixed in the bug-sweep tracker. Follow-up cleanup added the missing H4b resolved entry.

## Suspected risk areas

- `AudioEngine.runRecreationTransaction()` now owns multiple previously independent pathways. The tests cover coalescing, suppression, switch-task drain, permission downgrade, restore, and reconcile, but real coreaudiod restart behavior still deserves manual runtime observation.
- T6's reconcile updates live taps only when a stored tap exists. XCTest cannot store activated taps without real CoreAudio, so tap update behavior is compile-covered and state-covered, not hardware-verified.
- T7 intentionally removes crash-time HAL cleanup. The retained safety model is next-launch orphan cleanup plus graceful SIGTERM/SIGINT shutdown; truly unclean termination relies on the next launch to clean leftovers.
